# Clash X

基于 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev) 的二次开发。

核心能力仍与上游保持同步，UI与交互全面重构，更现代、更美观。

## 功能增强

- **节点页 · 智能切换**：允许自选一组优质节点，按延迟自动切换，避免整组盲切。
